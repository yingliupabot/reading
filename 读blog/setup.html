Setup：每日阅读设置

每天按下面四个兴趣类别找文章，挑出值得读的放进 读 Blog 的待读清单。

四个兴趣类别

  • GitHub 交易 / AI 短剧热门
  • GitHub 其他热门
  • YouTube 教育
  • 炒股新闻

每天怎么找文章

  1. 打开每个类别的来源，浏览当天的热门内容。
  2. 把标题、来源和类别记下来，先放进待读清单，不必当天全部读完。
  3. 去掉重复、过时或与类别无关的内容，保持清单简短可用。

每日挑选规则

  • 每天最多 4 篇，四个分类各 1 篇，找不到好内容就不凑数。
  • 每个类别都要覆盖，不只看最熟悉的一个类别。
  • 优先选与交易、AI 短剧、教育或炒股新闻直接相关的内容。
  • 优先选信息新、有来源、可验证的内容，避免标题党和重复转载。
  • 读完后从待读清单中移除，新的热门内容再补进来。
  • 清单保持按类别整理，方便每天按类别挑着读。
